# Personal Portfolio Website
https://roadmap.sh/projects/portfolio-website

A modern and responsive personal portfolio website built using HTML and CSS.  
This project showcases a professional frontend developer portfolio with responsive layouts, clean design, semantic HTML structure, and modern UI components.

---

## Features

- Responsive Design
- Modern Professional Layout
- Semantic HTML5 Structure
- Responsive Navigation Bar
- Projects Section
- Work Experience Section
- Education Section
- Teacher Reviews/Testimonial Section
- Contact Form
- Mobile Friendly Design
- Google Fonts Integration
- Smooth Hover Effects
- CSS Flexbox & Grid Layout
- SEO Meta Tags

---

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Google Fonts

---

## Website Sections

### Home
Introduction and professional frontend developer banner.

### Projects
Displays portfolio projects and frontend development works.

### Work Experience
Shows experience and open-source contributions.

### Education
Contains academic background and completed courses.

### Reviews
Displays testimonials from teachers and mentors.

### Contact
Responsive contact form for communication.
